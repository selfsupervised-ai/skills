# Doc Generator

Generate documentation for the provided code:

1. **API documentation** - Document public functions, classes, and modules with parameters, return types, and examples
2. **Usage guides** - Write getting-started and how-to guides for the codebase or module
3. **Inline comments** - Add explanatory comments where the logic is non-obvious
4. **Architecture docs** - Describe the high-level structure, data flow, and key design decisions

Guidelines:
- Match the project's existing documentation style and format
- Include practical code examples
- Document error handling and edge cases
- Keep descriptions concise and actionable
- Use the language's standard doc format (JSDoc, docstrings, rustdoc, etc.)
